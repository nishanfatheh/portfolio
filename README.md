# Phase 1 – Personal Website

## Overview
This is Phase 1 of the Web Programming Three-Phase Personal Website Assignment.
It is a standards-based personal portfolio created using HTML5 and CSS3.

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive media queries
- GitHub Pages

## Website Sections
1. Home
2. Profile
3. CV
4. Education & Technical Expertise
5. Projects
6. Activities / Gallery
7. Contact

## Phase 1 Requirements Demonstrated
- Semantic HTML5: header, nav, main, section, article, footer
- Headings, paragraphs, links, images and lists
- CV table using table, tr, th and td
- Contact form with labels, text inputs, radio buttons, checkbox, textarea and button
- HTML5 video element
- iframe embedding
- External CSS file
- CSS selectors, box model, typography, spacing and borders
- Flexbox and CSS Grid
- Responsive media queries
- Meta tags including viewport, description, author and keywords

## Before Submission
1. Replace "Your Name" with your actual name.
2. Replace the placeholder email and LinkedIn URL.
3. Add your own profile, project and activity images to the `images` folder.
4. Add your own video as `images/sample.mp4`, or remove the video element if you choose another permitted multimedia feature.
5. Check all personal details and project descriptions.
6. Create a public GitHub repository.
7. Upload the complete project.
8. Enable GitHub Pages.
9. Test the website on desktop and mobile.
10. Add the repository URL and live GitHub Pages URL to this README.
